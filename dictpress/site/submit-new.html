How to add a word — भोजपुरी सब्द कइसे जोड़ल जाव read first
  1. Search first. If the word is already here, don't add it again — open its entry and use the ✏️ Suggest an edit icon instead.
  2. Content — the word itself in Devanagari, in dictionary form: मड़ई, not मड़इया or a whole sentence.
  3. Pronunciation — optional. A romanization like maṛaī, or IPA if you know it.
  4. Definitions — set the language to English, pick the part of speech, and write one meaning per box. Use + Add another definition for each extra sense.
Example मड़ई  maṛaī  ·  Noun  →  1. thatched hut; a small cottage of straw and bamboo   2. small thatched shed for cattle or straw
Do
  • Dictionary form, not an inflected one
  • One sense per definition box
  • Short, plain English meanings
  • Note the region if the usage is local — “(Ballia side)”
  • Words Hindi doesn't have — those are the most valuable
Avoid
  • Whole phrases or sentences as the word
  • Roman-script headwords (use Devanagari)
  • Encyclopedia-style explanations
  • Hindi words not actually used in Bhojpuri
  • Meanings you are not sure about

Every submission is read by a moderator before it goes live, so a mistake costs nothing. Unsure of the spelling? Submit anyway and say so — we would rather fix a spelling than never learn the word exists. Regional variants are wanted, not a problem.
